# Occam

用于减法自检的 Agent Skill。结合第一性原理与奥卡姆剃刀，评估需求、方案、代码、文档和测试是否值得新增或保留。

完整方法与示例见 [SKILL.md](SKILL.md)。既可以随时手动调用，也可以由仓库流程指定调用。检查可能得出保留、简化或删减的结论；需要改变已确认的需求或支持范围时，先向协作者说明取舍。

## 安装

将本仓库放入你的 agent 支持的技能目录。例如，使用 `~/.agents/skills` 的环境可执行：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/yiz-liu/occam.git ~/.agents/skills/occam
```

目标目录已有内容时，先检查现有安装。已通过上述方式安装的副本，可在该目录执行 `git pull --ff-only` 更新；本地改动需自行保留和处理。

本技能只有文档，无需安装运行依赖。

## 使用

在支持 `$技能名` 的 agent 中，可以这样调用：

```text
$occam 检查这个方案，哪些需求有实际依据，哪些可以不做？
$occam 盘点 docs/，先给出保留、合并和删除建议，不修改文件。
$occam 检查本次完整改动，精简没有额外收益的实现和测试。
```

也可以在仓库的 `AGENTS.md` 中指定调用时机：

```text
决定动手实现前、创建或更新 PR 前，使用 occam 技能检查需求、实现、文档和测试的必要性。
```

调用时机由使用方决定。技能提供判断方法，不替代协作者授权、实际验证或技术审查。
