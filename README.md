# Occam

Occam 是用于减法自检的 Agent Skill，结合第一性原理和奥卡姆剃刀，判断需求、方案、代码、文档和测试是否值得新增或保留。

你可以随时手动调用，也可以由仓库流程指定调用。检查结果可以是保留、简化或删减；如果需要改变已确认的需求或支持范围，应先向开发者说明取舍。完整方法和示例见 [SKILL.md](SKILL.md)。

## 安装

在项目目录中运行：

```bash
npx skills add yiz-liu/occam
```

按提示选择使用的 agent。默认安装到当前项目；如需在所有项目中使用，在命令末尾加上 `-g`。

## 使用

在支持 `$技能名` 的 agent 中，可以这样调用：

```text
$occam 检查这个方案，哪些需求有实际依据，哪些可以不做？
$occam 盘点 docs/，先给出保留、合并和删除建议，不修改文件。
$occam 检查本次完整改动，精简没有额外收益的实现和测试。
```

也可以在仓库的 `AGENTS.md` 中指定调用时机：

```text
决定动手实现前、创建或更新 PR 前，使用 occam 技能检查需求、实现、文档和测试的必要性。
```
